# Simple Recipes Website

A beginner HTML and CSS project for the About Page Challenge.

## Open the website

Download this folder and open `index.html` in a web browser. Keep `style.css` in the same folder. No installation is required.

## Challenge requirements

- The `about` section is above the contact form in `index.html`.
- It has an About heading and the supplied About text inside a `div`.
- The navbar contains a list item linking to `#about`.
- `style.css` styles the About section with the site's green and cream colors.
- `scroll-behavior: smooth` enables smooth navigation; reduced-motion preferences are respected.
- Scroll margins keep section headings visible below the sticky navigation.

The contact form is a browser-only practice form. It validates required fields but does not send or store messages. The About copy is the sample text supplied by the assignment.

## Check it yourself

1. Open `index.html` and click About in the navbar.
2. Confirm the page scrolls to the About heading above Contact us.
3. Resize the browser to check the mobile layout.
4. Refresh and try the navigation again.
