# Bootstrap Footer Challenge

## Requirement

Create a footer using Bootstrap's grid system to organize multiple sections, such as contact information, social media links, and a copyright notice. The course permits fictional information.

## Files

- `index.html`: the example page and footer.
- `css/style.css`: page colors, type, spacing, and link focus styles.
- `css/bootstrap-grid.min.css`: the official Bootstrap 5.2.3 grid stylesheet, saved locally so the layout also works offline. Its MIT license notice is retained in the file.

## How the grid works

The footer uses `.container`, `.row.g-4`, and three `.col-12.col-md-4` sections. Each section uses all 12 columns on narrow screens. At 768 pixels and wider, each uses four of Bootstrap's 12 columns, so the three sections fit alongside each other. The `g-4` class supplies horizontal and vertical spacing.

The three sections contain contact details, social media links, and a copyright notice. Contact details are fictional. Social links go to the platforms' home pages, rather than claiming to represent real Academy Cinemas accounts.

## Open and check

Download the repository ZIP, extract it, and open `Bootstrap-Footer-Challenge/index.html` in a browser. Keep the `css` folder beside `index.html`.

Resize the browser to check the three columns at desktop sizes and the stacked sections on mobile. Press Tab to check that links have a visible focus outline. The email and phone links open the appropriate apps; the details are examples.
