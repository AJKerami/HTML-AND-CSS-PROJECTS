## Grid explanation

`main.container` wraps the page content. `.row.g-3` creates one row with gutters. Its two direct children each use `.col-6`, so each occupies six of Bootstrap's twelve grid units. They remain side by side at all Bootstrap breakpoints.

## Open the page

1. Download the repository ZIP from **Code → Download ZIP**.
2. Extract the ZIP.
3. Open `Bootstrap-Grid-Challenge/index.html` in Chrome or Edge.
4. Confirm that Column One and Column Two appear alongside each other. Resize the window to check the layout.

All required Bootstrap 5.3.3 assets are included locally, so this page can render offline. Keep the CSS and JavaScript folders beside the HTML file.
